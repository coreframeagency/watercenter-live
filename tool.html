                How we still know where calls come from
                
        
                With one number per branch, the number cannot tell us the source. Three signals do, and the handler never has to ask first.
                
        
                  
          
                1. Platform reports. Each ad platform reports the calls it sends: Google Ads call assets, Google Business Profile call counts, Meta call ads. To be confirmed in the Map phase.
                  2. 
          
                2. Click logs. The website call button and Meta click-to-call log the click with its source. A click cannot be tied to one specific call, so it counts as a signal, not a match.
                  3. 
          
                3. One optional tap. At the end of a call, if it came up naturally, the handler taps "Heard via". It is never the first question.
                  4. 
        
                
        
                If exact attribution matters later, add a small pool of extra numbers for the website only. That needs more 011 and 037 numbers from the provider.

This page is where we find out, with real Water Center recordings, which model is good enough to offer as an add-on. This page cannot run a model itself. You run a model on a recording, paste its output below, and the scorer compares it with a human transcript.
