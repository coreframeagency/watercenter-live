What we need from you

Five things to get started.

  1. 50 sample calls

    Real recordings, with consent. This is how we pick a transcript model, if you want one.

  2. Real numbers

    How many calls each branch gets in a month.

  3. Branch lines

    Your two branch numbers, so we can connect them to the desk.

  4. One owner per branch

    A manager who checks the follow-up queue every day.

  5. Your calendar

    A work Google or Outlook calendar, so follow-ups land as reminders.

Why these. They connect the desk to your real branches and set the targets for the first 100 calls report.
